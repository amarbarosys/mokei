# mokei v0.1.0

First public release.

- Line counts per language for 40 languages from `languages.toml`, with embedded languages (HTML `script`/`style`, Markdown fences) as child rows; output as a table, per file, or JSON.
- Matches tokei 15.0.0 on the test fixtures; differences on real corpora are listed in `docs/known-diffs.md`.
- Questions tokei does not answer: `--diff A..B --budget XS|S|M|L`, `--tokens` and `--tokenizer`, `--dupes N`, `--untested`, `--semantic`.
- Linux only. Built with Mojo 1.2.0 (`pixi run gate`).
